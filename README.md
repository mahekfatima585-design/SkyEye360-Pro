AI-powered surveillance software built for Raspberry Pi. Tested 
for real installs with simulation mode and automated tests.


[▶️ Watch the demo video](https://raw.githubusercontent.com/mahekfatima585-design/SkyEye360-Pro/07001a673943bb80149d097e65cc05f16a62fa0f/SkyEye360_Sales_EN.mp4)


## Features

- AI Object Detection — detects person, vehicle, and animal in real-time
- Smart Tracking — automatically follows objects in real-time
- Instant Alerts — Telegram / Email / WhatsApp notifications
- Custom Zones — set your area of interest with flexible zones
- SQLite Database — save events & logs securely
- Docker Support — easy deployment with Docker Compose
- Easy Configuration — setup wizard + ready presets (Shop / Home Gate / Warehouse)
- System Health Monitor — track system status and performance
- Live web dashboard with authentication
- Up to 120-day local recording

## Tech Stack

- Python 3.8+
- Linux (Ubuntu) — optimized for Raspberry Pi
- Flask (web dashboard)
- YOLO (AI object detection)
